# TAB@Anti-Scam — הרצת השרת (server.js)

השרת מחבר שיחת טלפון אמיתית למערכת: עונה לשיחה נכנסת, מחבר אותה לטלפון של האדם המוגן, מתמלל את שני הצדדים בזמן אמת ומזהה את 5 סימני ההונאה. כל מה שקורה משודר חי למסך המפעיל.

**האדם נשאר בשליטה. TAB לעולם לא משתלט על שיחה מעצמו.**

## איך זה עובד

| שלב | מתי | מה קורה |
|---|---|---|
| פתיחה | כשהשיחה נכנסת | המתקשר שומע "השיחה מוקלטת לצורכי אבטחה" (ברוסית ובעברית). זה מכסה את האדם מבחינה משפטית ומרתיע נוכלים כבר בהתחלה. |
| אזהרה | בסימן השלישי | המתקשר מועבר להמתנה לכמה שניות, ורק האדם שומע את TAB: "השיחה הזו נראית כמו הונאה. אל תמסרו קודים ואל תעבירו כסף. אני כאן לידכם, אל תדאגו." המשפחה מקבלת הודעת וואטסאפ עם התמליל עד עכשיו. |
| הצעה | בסימן הרביעי | האדם שומע איך להעביר את השיחה ל-TAB: לומר את משפט ההסכמה, או ללחוץ 9. |
| העברה | רק אחרי הסכמת האדם | האדם שומע "לקחתי את השיחה, אפשר לנתק בשקט". המתקשר שומע את הקול שהאדם בחר (ברירת מחדל: השכנה נאדיה). המשפחה מקבלת הודעה שנייה. |

שליח שבא לאסוף מזומן או צ׳ק נספר כסימן נוסף, ומקבל נוסח אזהרה משלו. האדם יכול לומר את משפט ההסכמה בכל שלב, גם לפני שזוהה סימן כלשהו.

## מה צריך

- Node.js 18 ומעלה
- חשבון Twilio + מספר טלפון בחשבון
- מפתח API של Deepgram (תמלול)
- ngrok (כדי לחשוף את השרת המקומי לאינטרנט)
- לוואטסאפ: Twilio WhatsApp (ה-Sandbox מספיק לבדיקות)

## 1. התקנה

```bash
npm install
```

## 2. משתני סביבה

```bash
export DEEPGRAM_API_KEY=...          # תמלול
export TWILIO_ACCOUNT_SID=...
export TWILIO_AUTH_TOKEN=...
export TWILIO_NUMBER=+1XXXXXXXXXX    # מספר ה-Twilio שלכם (ממנו מחייגים לאדם המוגן)
export ELDER_PHONE=+9725XXXXXXXX     # הטלפון של האדם המוגן
export ELDER_NAME="אמא"              # איך האדם מופיע בהודעות למשפחה
export PUBLIC_HOST=xxxx.ngrok.app    # הכתובת מ-ngrok, בלי https://
export CONSENT_PHRASE="мой сын рядом" # המשפט שהאדם אומר כדי להעביר את השיחה ל-TAB
export OPERATOR_TOKEN=...            # סיסמה למסך המפעיל (אם לא מוגדר, נוצרת אחת אקראית ומודפסת בהפעלה)
export FAMILY_WHATSAPP=+9725...,+9725...       # מי מקבל הודעות
export WHATSAPP_FROM=whatsapp:+14155238886     # מספר הוואטסאפ של Twilio (כאן: ה-Sandbox)
```

אופציונלי:

```bash
export STT_LANGUAGE=ru               # ru (ברירת מחדל) או he
export WHITELIST=+9725...,+9725...   # מספרים שלא מנוטרים (משפחה)
export WARN_AT=3                     # כמה סימנים עד אזהרה
export OFFER_AT=4                    # כמה סימנים עד הצעת העברה
export CONSENT_DIGIT=9               # המקש להסכמה
export PERSONA_NAME="השכנה נאדיה"     # השם במסך המפעיל
export PERSONA_VOICE=Polly.Tatyana   # Tatyana = אישה, Maxim = גבר
export DEMO_MODE=1                   # מפעיל את נקודות ההדגמה (ראו למטה)
```

כל הנוסחים ניתנים להחלפה דרך משתני סביבה: `NOTICE_RU`, `NOTICE_HE`, `WARN_LINE`, `WARN_LINE_COURIER`, `OFFER_LINE`, `HANDOFF_LINE`, `PERSONA_LINE`, `PERSONA_LINE_COURIER`.

## 3. הרצה

בטרמינל אחד:

```bash
node server.js
```

בטרמינל שני:

```bash
ngrok http 8080
```

מעתיקים את כתובת ה-https שמופיעה ב-ngrok, מעדכנים את `PUBLIC_HOST` ומריצים שוב את השרת.

## 4. חיבור ל-Twilio

בקונסולת Twilio → Phone Numbers → המספר שלכם → Voice Configuration:
**A call comes in → Webhook →** `https://<PUBLIC_HOST>/voice` (HTTP POST)

## 5. חיבור מסך המפעיל

התמלולים החיים פרטיים, ולכן כל חיבור למסך המפעיל דורש את `OPERATOR_TOKEN`. השרת מדפיס את הכתובות המלאות בהפעלה.

- **מסך המפעיל החי (v2):** בשדה הכתובת מזינים `wss://<PUBLIC_HOST>/operator?token=<OPERATOR_TOKEN>` ולוחצים "התחבר".
- **או** פותחים את הדשבורד המובנה של השרת: `https://<PUBLIC_HOST>/?token=<OPERATOR_TOKEN>`

## הדגמה בלי טלפון ובלי מפתחות

עם `DEMO_MODE=1` אפשר להריץ את כל התהליך בלי Twilio ובלי Deepgram, ולראות אותו במסך המפעיל:

```
/demo/call?token=<OPERATOR_TOKEN>                                        → פותח שיחה ומחזיר callSid
/demo/say/<callSid>?token=<OPERATOR_TOKEN>&speaker=caller&text=...       → משפט של המתקשר
/demo/say/<callSid>?token=<OPERATOR_TOKEN>&speaker=person&text=...       → משפט של האדם (למשל משפט ההסכמה)
/demo/press/<callSid>?token=<OPERATOR_TOKEN>&digit=9                     → לחיצת מקש של האדם
```

בלי פרטי Twilio, הלחישות, הודעות הוואטסאפ וההעברה מוצגים במסך המפעיל כסימולציה.

## מה השרת משדר למסך המפעיל

| אירוע | מה הוא עושה |
|---|---|
| `call_start` | שיחה חדשה נכנסה |
| `ttype` | סוג האיום: `phone` (קוד/כרטיס) או `courier` (שליח פיזי) |
| `transcript` | שורת תמלול (`caller` / `person`) |
| `signs` | אילו מתוך 5 הסימנים זוהו |
| `pressure` | רמת לחץ 0–100 |
| `stage` | מעבר שלב: `warn`, `offer`, `takeover` |
| `whisper` | מה האדם שמע מ-TAB (המתקשר לא שומע) |
| `notify` | ההודעה שנשלחה למשפחה |
| `takeover` | הקול שהאדם בחר נכנס לשיחה |

## כללי בטיחות שמובנים בקוד

- **מספרי חירום** (100, 101, 102, 112) מחוברים ישירות — ללא ניטור, ללא הודעת הקלטה וללא התערבות. אין לשנות.
- **אין השתלטות בלי הסכמה.** TAB מזהיר, מציע ומודיע למשפחה, אבל מעביר את השיחה רק אחרי שהאדם אמר את משפט ההסכמה או לחץ על המקש.
- **הקול שנכנס לשיחה הוא בחירת האדם.** האדם מזמין את "השכנה" לשיחה; זו לא התחזות של המערכת.
- **מילים שלמות בלבד**: הזיהוי לא מתבלבל בין "код" ל"кодекс" או בין "קוד" ל"קודם".
- **מסך המפעיל מוגן בטוקן**, ונקודות ההדגמה סגורות כברירת מחדל.

## נקודות לשים לב

- **מספר מזהה:** האדם המוגן רואה את מספר ה-Twilio, לא את המספר של המתקשר. המספר המקורי מופיע בהודעה למשפחה ובמסך המפעיל.
- **לחיצת מקש בזמן שיחה** תלויה בהגדרות חשבון ה-Twilio, ולא בכל הגדרה היא מגיעה לשרת. משפט ההסכמה עובד תמיד, לכן כדאי לבדוק לחיצה מול החשבון לפני דמו.
- **וואטסאפ:** ה-Sandbox של Twilio מתאים לבדיקות. לשימוש אמיתי, הודעה יזומה לאדם שלא כתב לכם ב-24 השעות האחרונות דורשת תבנית הודעה מאושרת (WhatsApp template).
- **משך הלחישה** מחושב לפי אורך הנוסח, ואחריו המתקשר חוזר מההמתנה. אם משנים נוסחים, לבדוק שהזמן מספיק.
- **קול עברי** בהודעת ההקלטה משתמש בקול של Google דרך Twilio (`HE_VOICE`). לוודא שהוא זמין בחשבון.
- תמלול בעברית ב-Deepgram פחות יציב מרוסית — לבדוק מול החשבון לפני הדמו. אם חלש, להריץ ברוסית בלבד.
- כתובת ה-ngrok משתנה בכל הרצה (בגרסה החינמית) — לעדכן גם ב-Twilio וגם במסך המפעיל.
- **לא להעלות את המפתחות ל-Git.** הכל דרך משתני סביבה בלבד.
